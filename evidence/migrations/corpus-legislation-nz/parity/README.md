# Invalidated generated parity evidence

The JSON files retained in this directory were generated by the superseded
`tools/generate_executable_legislation_parity.py`. They are preserved as
historical provenance but are **not valid operational, parity, publication,
coverage, or completeness evidence**.

The generator could substitute fixed counts (68 batches and 33,693 works),
fixtures, a synthetic publication package, and an unobserved endpoint while
still producing aggregate `status: passed`. None of these receipts may satisfy
the real-batch, workflow, publication, rights, recovery, cutover, or donor
archival gates.

The replacement `tools/reconcile_one_legislation_batch.py` accepts one explicit
donor batch and its expected canonical SHA-256 plus real target manifest,
checkpoint, and CAS paths. It fails non-zero on missing or divergent state. A
new passed receipt must not be committed until the ordered real-batch execution
gate is reached and the actual bounded run has been independently reviewed.
