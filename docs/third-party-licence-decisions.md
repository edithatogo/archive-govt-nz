# Third-party licence decisions

## text-unidecode 1.3

Status: Artistic License alternative selected

`ckanapi` 4.11 depends on `python-slugify`, whose default transliteration
dependency is `text-unidecode` 1.3. The installed distribution declares
`License: Artistic License` and also publishes Artistic and GPL Trove
classifiers. For this repository, the offered Artistic License alternative is
selected.

The supply-chain gate encodes this as a package-specific decision. It does not
permit an unknown package merely because a permissive phrase appears beside a
denied copyleft term. Version changes remain subject to the locked dependency
audit and licence inventory.
