# Specification

Build distinct, explicitly unofficial Bluesky archive mirrors for canonical NZ government identities. Registration is operator-supervised locally; ongoing and historical publication uses account-isolated AT Protocol credentials in GitHub Actions. Archive workflows remain incapable of posting.

Acceptance requires a canonical registry, issue/track evidence, compliant profiles, isolated environments, dry-run preflight, idempotent publication, public readback, four-per-day backfill, incident pause, and reporting. Account configuration alone is not completion.
