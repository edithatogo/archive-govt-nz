# Specification

## Overview and authoritative inputs

Complete Prompt 20 issue [#351](https://github.com/edithatogo/archive-govt-nz/issues/351)
against the final integrated head. The original Prompt 20 operating contract,
`conductor/workflow.md`, `conductor/autonomy.md`, and `AGENTS.md` control this

preparatory evidence, not the final selected head.

## Acceptance criteria

AC1: Complete full local and exact-head hosted validation, including all
supplementary state, restoration, configuration, accounting and readback suites.
AC2: Preserve failures, exact hashes, software/environment identities,
reproducible packages, and bounded real-state resource results.
AC3: Verify no unresolved high/critical vulnerability, credential finding,
schema failure, critical surviving mutant, or unexplained flaky failure remains.
AC4: Record enforced ruleset, corrective PR lineage, final independent review,
and a reproducible integrated assurance receipt before closing issue #351.

## Constraints and gates

The opt-in hosted harness only executes existing tests with read-only permission.
No thresholds, production logic, datasets, secrets, rights, or public metadata
change. Dataset publication, operational acquisition, DOI actions and other
external changes are outside scope. Existing user authorization covers the
repository assurance workflow; explicit workflow opt-in remains mandatory.
