# Requirements

## Must

- Preserve the source/derivative, discovery/capture, admission, rolling, and
  immutable-release distinctions from `docs/archive-system-architecture.md`.
- Verify the target repository's own trust boundaries before proposing edits.
- Keep external repository changes, credentials, and publication behind explicit
  human and repository-owner gates.

## Must not

- Copy the architecture blindly into unrelated repositories.
- Claim fyi-archive adoption from this planning track alone.
- Publish or alter a remote dataset, release, or DOI.
