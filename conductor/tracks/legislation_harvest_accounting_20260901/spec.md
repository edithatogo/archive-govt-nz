# Specification

Replace ambiguous legislation harvest counters with a typed, versioned receipt whose per-work terminal dispositions reconcile discovery, scope, attempts, state-record changes and CAS-object changes. The service must produce the accounting at the point each work is processed; runners and CLI consumers must project it without inventing stronger claims. Historical v2 receipts remain readable as ambiguous legacy evidence. This track does not change schedules, durable destinations, publication metadata or coverage claims.
