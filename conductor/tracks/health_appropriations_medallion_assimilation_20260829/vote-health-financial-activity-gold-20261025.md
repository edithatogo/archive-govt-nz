# Vote Health 2014/15 financial-activity Gold projection

This bounded Phase 6 product projects the retained page-7 2014/15
Supplementary Estimates Silver facts into a separately versioned Gold package.
It preserves the source-reported values, all 14 row identities, the five
`$000` columns, printed row ordinals, and 70 field-level source coordinates.
The read-only DuckDB query is limited to this source context and 14 rows.

The public Treasury response used for this full build matched the already
captured Bronze object at 356,801 bytes and SHA-256
`99e90dfddd8fc7b6d2bb545148d95f8f3c4c3cbf77760b91103130304176780e`. Two
independent Silver-to-Gold builds produced identical manifests and output
payload digests. The exact manifest pins and payload hashes are in
`vote-health-financial-activity-gold-20261025.json`.

The package does no arithmetic, aggregation, edition comparison, currency
interpretation, donor reconciliation, or cross-source join. The source page
remains partially normalized; rights remain unevaluated and publication was
not performed. This closes only this product's pinned Silver-to-Gold projection
and query slice; Phase 6 source/donor controls, wider report and plot coverage,
and the final checkpoint remain open.
