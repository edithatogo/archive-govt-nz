# Additive readable canonical Gold plots

The frozen v1 canonical renderer clips long source captions and record hashes in
Budget 2025 revenue charts. Keep those Gold bytes unchanged. A separate local
package consumes the independently pinned, verified canonical Gold package and
renders the existing eight discrete financial product families in pages of at
most eight observations. BIFF8 financial displays remain explicitly excluded;
this derivative does not qualify their amount scale. The separate context Gold
renderer and its inputs are outside this canonical package contract.

Each point has an ordinal, exact Decimal string, complete input record IDs and
the full typed source row in `plot-points.json`. The display may shorten wrapped
captions with an explicit sidecar notice; source labels and qualifiers are never
shortened in the sidecar. Dates use ISO strings. Float conversion is for display
only. Context groups, vintages, units and product families remain separate; no
netting, pooling, deflation, period inference or source aggregation occurs.

Preserve the existing 32 groups per product, 500 points per group, 4,000 total
points and 32 MiB derivative budget. Excluded groups retain reason codes and IDs.
The manifest pins the parent manifest, every output and renderer version, with
rights unevaluated and publication not performed. Visible text extents must fit
the canvas after actual rendering. Geometry checks complement native visual
inspection; neither implies financial comparability or rights admission.

`export_readable_plots` defaults to a dry run. It verifies the parent and typed
products before reserving output, rejects overlapping/existing paths, reuses the
existing descriptor-relative exclusive writer and checks persisted hashes.
A partial failure is retained with a failure marker when possible. Windows uses
the existing repeated-identity fallback under a trusted parent; it is not a
hostile-filesystem transaction. The parent remains read-only.
