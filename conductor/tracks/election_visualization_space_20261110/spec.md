# Track Spec: Interactive Election Visualization Space

Deploy a full-featured, zero-cost interactive visualization application to Hugging Face Spaces (`edithatogo/nz-election-explorer`) and GitHub Pages (`edithatogo.github.io/archive-govt-nz`). Provide dynamic parliamentary semi-circle diagrams, overhang breakdown, interactive special-vote scenario sliders, coalition majority calculators, and GIS choropleth boundary maps.
