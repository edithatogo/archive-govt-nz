# Track Spec: MMP Sainte-Laguë Allocation & Overhang Engine

Implement a mathematically rigorous, zero-dependency engine implementing the Sainte-Laguë allocation algorithm defined in the New Zealand Electoral Act 1993 (Schedule 4). The engine must evaluate the 5% threshold, coat-tail exemptions, quotient sequencing, overhang seat creation, House expansion math, and dynamic coalition majority thresholds.
