# Requirements

## Must

- Select the governed 500-work seed by stable registry ID and exact hash.
- Authenticate a complete lineage-bound parent before source access; never infer
  bootstrap from a failed restoration.
- Force live revalidation of every ID without search discovery or permitted skip.
- Preserve v3 dispositions, reconcile identities/accounting/CAS, and seal a
  complete continuation package.
- Serialize canonical-state writers, retain every attempt, expose only the source
  secret, and enforce explicit work/time/byte/retry/state bounds.
- Add failure-path and policy tests and a downstream runbook.

## Must not

- Dispatch the hosted proof, publish externally, alter donor state, or claim full
  legislative coverage.

## Acceptance

The workflow cannot reach acquisition with an absent, corrupt, wrong-scope or
unsealed parent or seed. A successful run represents all and only the 500 governed
IDs, has zero unexplained reconciliation mismatch, and yields an independently
verifiable Prompt 13 continuation package.
