# NZ legal and parliamentary archive delivery order

1 November 2026. This is the operational order for the remaining archive work. Each owner uses the repo-local Python 3.15.1 CLI and the existing source-specific rights and withdrawal rules. Each row names one discriminating test and one acceptance operation. The latter checks the whole partition or packet. Reuse its receipt when inputs match. Required integration gates still apply to code changes.

**Page 1 completed.** All 95 continuation works have full version lists. Across 140 expressions, 278 formats were already archived and packet C added the remaining 165. One anonymous pinned readback matched the index and ZIP. The first five works were handled in the seed packet.
