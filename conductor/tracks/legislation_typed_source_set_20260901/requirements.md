# Requirements

- Must use safe proper YAML parsing, duplicate detection, strict booleans and size/regular-file bounds.
- Must reject unknown, mistyped, contradictory and unsupported v2 values before action.
- Must provide immutable nested typed models and one schema.
- Must route CLI and harvest runner through the loader.
- Must distinguish supported capability from inactive publication/external actions.
- Must represent discovery and exact-inventory scopes separately.
- Must preserve deterministic migration of the known v1 legislation document.
- Must test failures, properties, coverage and targeted mutations.
