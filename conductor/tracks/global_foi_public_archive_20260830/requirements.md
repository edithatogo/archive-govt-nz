# Requirements — MoSCoW

acceptance, not claims about track initialization. See approval.json and recommendations.md.

No unapproved owner change. Ownership is approved; execution remains gated by parity and restore. |

Prove one hosted continuation beyond the blocked range. |

Prove country-set equality and provenance. |
| R05 / AC05 | Must | Preserve original metadata bytes and generate JSONL/Parquet metadata indexes with stable IDs, source URL, instance/country, object relationships, observation/capture timestamps, media type, byte count, SHA-256, raw-object path, version, rights disposition and failure state. Every successful row resolves to a verified raw object; excluded data never leaks into public metadata. |
| R06 / AC06 | Must | Store original pages, metadata responses, correspondence, decisions and attachments byte-for-byte in CAS and durable public HF packages where eligible. Preserve HTTP/WARC context where applicable. No synthetic record, CDX listing or extracted sample counts as original capture. Validate redirects against private-network access; bound decompression and parsing, never execute attachments, and quarantine unsafe objects from public exports. |
| R07 / AC07 | Must | Publish a discoverable global index plus country/instance metadata and raw-object manifests with immutable HF revisions, hashes, dataset cards and reciprocal links. Test public and ungated access anonymously and restore every file in each accepted bounded publication; reconcile global indexes to per-instance manifests. The global snapshot pins every child revision and manifest digest; failed/interrupted publication leaves the prior verified catalogue current. |
| R08 / AC08 | Must | Schedule bounded source discovery, historical backfill, incremental change capture and publication for all approved supported sources, with independent queues, durable state, lease fencing, backoff, pacing, costs, restart recovery and fair country scheduling. Export accepted raw objects, manifests and checkpoints to durable storage before temporary artifact expiry and reconcile earliest-expiring backlog first. Enforce per-source/global byte, runtime, request and retry budgets; preserve object identity across sharding/compaction. Preserve revisions, deletions, tombstones and takedown corrections. |
| R09 / AC09 | Must | Report discovery, capture, integrity, upload, anonymous verification, freshness and complete-snapshot states separately. Use enumerated denominators; unknown means null. | R10 / AC10 | Must | Run shadow parity without duplicated origin load; match queues, cases, events, attachments, raw hashes, revisions, checkpoints, retries and takedown behavior. Cut over exactly one active owner only after hosted parity and public restore; maintain a rollback window and donor preservation. |

Do not change content licences to the repository software licence. |
